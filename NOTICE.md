AayushOS is adapted from **portfolio-inner-site** by **Henry Heffernan**:
https://github.com/henryjeff/portfolio-inner-site

That repository has no open-source licence. Henry gave Aayush Agrawal permission to use

notice, the README and the in-site Credits window are that credit.

What was kept from Henry's code: the React window manager (windows, outline drag and
resize, taskbar, Start menu, desktop shortcuts), the showcase site layout, the Wordle
game and the shutdown sequence structure.

What was changed or removed: all of Henry's personal content (bio, experience, projects,
pictures, music and resume) was replaced with Aayush's own. The DOS games, the Microsoft
fonts, Adobe fonts and Windows icons were removed and replaced with open-licence fonts
and icons drawn for this site. Terminal, Tetris, Paint and Recycle Bin come from
AayushOS Lite (Aayush's own code).

Permission covers this portfolio only. If you fork this repository, ask Henry before
reusing the code in `os-app/`.
