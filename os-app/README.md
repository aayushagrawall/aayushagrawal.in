# AayushOS

The desktop that runs on the monitor of [aayushagrawal.in](https://aayushagrawal.in), served at `/os/`.

Adapted from Henry Heffernan's [portfolio-inner-site](https://github.com/henryjeff/portfolio-inner-site), **used with his permission**. See `../NOTICE.md`.

```bash
npm install --legacy-peer-deps
npm start        # http://localhost:3000
npm run build    # the root "npm run build" copies build/ to public/os
```
